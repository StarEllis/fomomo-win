# 买入按原生币数量计价，报价只问一次，美元只做显示

交易卡的买入金额是 ETH / BNB / SOL / MON 的数量（快捷额按原生币分组），卖出只按持仓百分比；报价只在用户输入数量 / 点快捷额时问 OKX `/quote` 一次，没有周期刷新、也不依赖任何价格；点买 / 卖时 `/swap` 现取新路由和未签名交易，成交保护靠 autoSlippage（≤15%）与价格影响保护，与展示价无关。美元估值来自后台每 60s 缓存的原生币价（DexScreener），只做显示与 USD 限额校验——拉不到就显示「—」，报价照常出，只有买入执行会因无法校验限额而拒单。

## Considered Options

- 按 USD 计价：每次报价前要先学一次原生币价（冷链两次串行请求），报价明显变慢，且 USD → 原生币折算本身就是另一份误差。
- 周期刷新报价：多人开着卡每几秒刷会把共享的 OKX 配额吃光，而展示价对成交没有约束力。

## Consequences

- 报价超过 30s 只是变灰提示过期，不自动重报；执行必须钉住某一份报价的 id（防重放 / 防金额不一致）。
- 账本记录的 usd 是估值，不是成交额。

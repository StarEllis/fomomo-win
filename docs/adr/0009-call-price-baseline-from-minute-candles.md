# 喊单价基准：live 喊单取首次现价，回灌喊单取 gmgn 分钟蜡烛的 open

面板上的「喊后 ▲x%」是跟单收益视角——以**喊单那一刻**的价格为基准，不是市场 1h / 24h 涨跌。消息到达 ≤180s 的 live 喊单用首次拉到的现价，精确；启动回灌的历史喊单没有当时价，用 gmgn 分钟蜡烛在喊单所在分钟的 open（按喊单时刻 ±30min 聚簇，一簇一请求）。蜡烛还没覆盖到时暂用 gmgn 的历史价桶（1m/5m/1h/6h/24h 里最近的一个）近似并标 `≈`，蜡烛到了再覆盖。

## Considered Options

- 只用历史价桶：拉盘币上桶近似能差两个数量级（实测 +5.2K% vs 蜡烛 −58%），只配做过渡显示。
- 用市场 5m/1h 涨跌代替：不是用户要的口径——用户问的是「按喊单时买入现在赚多少」。

## Consequences

- 市值蜡烛（`token_mcap_candles`）与价格蜡烛（`token_candles`）分开拉：K 线画市值，定价用价格。
- 涨跌与 K 线优先按市值算，对新币收录初期 decimals 抖动免疫。
